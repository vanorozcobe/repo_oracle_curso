# Repositorio de Challengers - Curso Oracle  

Este repositorio ha sido creado para almacenar y organizar los **challengers del curso de Oracle**.  

## Contenido  
El repositorio incluye proyectos y ejercicios prácticos en:  
- **Python**  
- **HTML y CSS**  
- **Ciencia de Datos**  

## Librerías utilizadas en Ciencia de Datos  
- **NumPy**: para cálculos numéricos y manejo de arreglos.  
- **Pandas**: para la manipulación y análisis de datos.  

## Objetivo  
La finalidad de este repositorio es centralizar las soluciones y avances de los retos planteados durante el curso, facilitando el seguimiento del aprendizaje y la práctica en distintas áreas de desarrollo y análisis de datos.
